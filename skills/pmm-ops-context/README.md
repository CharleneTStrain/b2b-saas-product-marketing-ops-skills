# PMM ops context

**The problem:** Every skill needs the same background about your company, so you end up re-explaining your product, buyers, sales motion, leaders, and launch tiers every time.

**What it does:** Writes that background down once in `.agents/pmm-ops-context.md` — product, buyers and users, how it's sold, who signs off, launch tiers, where claims and sales content live, the numbers PMM is held to, and the main competitors. Every other skill reads it first and only asks for what's missing. Gaps are marked "Not recorded," never guessed. If you already have a product ops or product marketing context file, it drafts from that.

**Use it with:** positioning docs, launch briefs, sales decks, the website, an org chart, or a short conversation.

**You get:** a one-page, versioned context file with a changelog, kept current as the company changes.
